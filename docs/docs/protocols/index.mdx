# Protocols

The Shield speaks the **Agent Client Protocol** (ACP, protocol version 1) on both faces: an ACP agent towards the client, an ACP client towards the agent it launched, on the official `agent-client-protocol` SDK. `session/update` is normalised into the package's own events (text, thought, tool call, plan, commands, mode, permission, question); a malformed update ends the turn with a sentence.

What the Shield lends an agent: the MCP servers the policy's `mcp.allow` names, in `session/new`; nothing else. What it answers itself: `fs/read_text_file`, `fs/write_text_file`, `terminal/*`, each a decided and recorded action the client sees as a tool row.

## Authority across the chain

A caller that delegates work — an orchestrator, Datalayer's control plane — hands the Shield the execution's own credential in `_meta.datalayer.credential`. The Shield is where it stops: the agent is handed `_meta` with `"credential": "withheld"` in its place, at `session/new` and at every prompt, and never the token. Handed at `session/new`, it becomes the `Authorization` of every HTTP MCP server the session is lent, whatever the client wrote there, so the gateway decides every call the agent makes through them — and every call a **sub-agent** it spawns makes, since a sub-agent reaches MCP through the servers its parent was lent. A read-only manifest therefore stops a sub-agent's write at the gateway. A stdio server cannot carry the credential without putting it in the agent's arguments or environment: a session given both is refused in a sentence. A prompt carrying a credential the session was not lent with is refused too — its tools would act with another authority; open a session with it. The audit says a credential was lent, never which.

Over the wire, `agent-shield serve` speaks the two transports the ecosystem's bridges use — WebSocket (one JSON-RPC message per text frame) and ACP Streamable HTTP (`POST /acp` in, SSE streams out, `Acp-Connection-Id` and `Acp-Session-Id` headers) — as [serve and registration](../serve/) describes.

**Built:** ACP on both faces over stdio, WebSocket and Streamable HTTP. **Not built:** the A2A, AG-UI and other faces of the Shield are Datalayer's runtimes', not this package's.
