## `agent_shield.policy.model`

- `Rule` — One line of a policy: what it matches and what it decides.
- `Threshold` — A soft threshold asks once; a hard one refuses each call that would cross it.
- `Limits` — The stateful limits of a session.
- `Network` — What the agent may reach over the network, through the Shield.
- `Mcp` — The MCP servers the agent is lent, by name; everything else is cut from session/new.
- `Harnesses` — The harnesses an organization admits, and whose credentials run them.
- `Dogwood` — A Dogwood policy set (Cedar, and ``when temporal`` over the session's events), AC-42.
- `Rate` — A rate: at most ``rate`` per ``per``.
- `RateLimits` — What each person may spend through the organization's AgentCore Gateways (AC-45).
- `Policy` — One policy document, one scope.
- `Action` — What the agent wants to do, as the engine sees it.
- `Decision` — What the engine answered, and from where.
- `Settings` — Bounds that keep the schema's text readable in a sentence.
