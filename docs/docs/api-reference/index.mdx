# API

## Python: `agent_shield`

- `agent_shield.policy`: `Policy`, `Rule`, `Limits`, `Harnesses`, `Action`, `Decision`, `decide`, `decide_budget`, `widening`, `check_tightens`, `PolicyWidens`, `admits`, `credentials_rule`, `default_policy`, `load_policies`, `policy_json_schema`, `class_of`, `flagged`.
- `agent_shield.saas`: `ManagedPolicies` (`pull`, `in_force`, `push`, `watch`), `IamPolicySource`, `PolicyUnavailable`, `ServedPolicies`.
- `agent_shield.acp`: `StdioACPChannel`, `WebSocketACPChannel`, `normalize`, `Workspace`, `Terminals`; `agent_shield.acp.proxy.ShieldProxy`, `serve_stdio`.
- `agent_shield.audit`: `AuditLog`, `redact`, `diff_summary`.
- `agent_shield.register`: `catalogue`, `harness`, `credential_refusal`.

## TypeScript: `@datalayer/agent-shield`

The policy document's types (`Policy`, `Rule`, `Limits`, `Harnesses`, `Decision`), the constants (`SCOPES`, `ACTION_CLASSES`, `VERDICTS`, `TOOL_KINDS`, `KIND_CLASS`, `VERDICT_WORDS`, `LIMIT_NAMES`, `LIMIT_WORDS`, `CREDENTIALS`), `classOf` and `describeDecision`; `schema/policy.schema.json` exported. The diff and terminal renderers are not built yet.
