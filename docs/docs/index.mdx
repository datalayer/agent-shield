# 🤖 🛡️ Agent Shield

**A runtime firewall for every agent.** Deploy a shield with each agent. Enforce permissions before actions execute, manage policies centrally, and retain an audit trail.

`agent-shield run -- <command>` starts any [Agent Client Protocol](https://agentclientprotocol.com) agent — Claude Code, Codex, Gemini CLI, Goose, OpenCode, OpenHands — as its subprocess and stands as an ACP agent in front of it. Any ACP client sees one agent; the Shield decides, confines and records in between.
